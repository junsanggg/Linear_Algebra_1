## 커밋 메시지 컨벤션

`타입: 내용` 형식으로 작성합니다.

- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `docs`: 문서 수정 (README 등)
- `style`: 코드 스타일 수정 (포맷팅, 세미콜론 등 로직 변경 없음)
- `refactor`: 코드 리팩토링
- `chore`: 빌드 설정, 패키지 매니저 설정 등 (코드 로직 변경 없음)
